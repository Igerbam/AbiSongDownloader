Automatischer Download von Songs, die bei der Abi-Zeugnis-Vergabe abgespielt.\
Jede_r Schüler_in kann einen Song mit Zeit-Stempel als YouTube-Video auswählen.\
Besagtes Video wird automatisch heruntergeladen und auf die gewünschte Stelle zugeschnitten.\
Eingabe des Namens, des Links und des gewünschten Zeit-Stempels erfolgt in der Konsole.\
Man kann den Prozess aber automatisieren wenn man eine lange Liste in das Konsolenfenster kopiert.

Aufbau der Liste:

1 (Nachname), (Vorname)\
(YouTube URL)\
(Start-Minute)\
(Start-Sekunde)\
2 (Nachname), (Vorname)\
(YouTube URL)\
(Start-Minute)\
(Start-Sekunde)\
2 (Nachname), (Vorname)\
(YouTube URL)\
(Start-Minute)\
(Start-Sekunde)\
...
